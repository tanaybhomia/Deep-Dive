# Welcome to the Deep Dive Wiki!

Deep Dive is a focused productivity application built natively for the GNOME desktop environment. It goes beyond standard Pomodoro timers by introducing strict mechanisms designed to prevent cheating and enforce true deep work.

This Wiki serves as the central documentation hub for both users and developers. Use the sidebar on the right to navigate through the official brand guidelines and detailed user manuals.
